# PDF Мастер — редактор PDF и помощник юриста — настольный редактор PDF для Windows

## Установка и обновление

Один и тот же файл — **`update.bat`** — и устанавливает программу, и обновляет её.

**Первый раз / обновление с версии 1.0:** распакуйте архив и дважды щёлкните `update.bat`.
Скрипт найдёт Python (если его нет — предложит установить), соберёт программу
в `%LOCALAPPDATA%\PDFMaster-build`, закроет открытый PDF Мастер и поставит новую версию туда,
где стоит старая, а в конце сам её запустит:
- если программа была установлена установщиком — обновит её на месте (ярлыки и «Открыть с помощью» сохранятся);
- если была просто собрана — положит её в `%LOCALAPPDATA%\Programs\PDFMaster` и обновит ярлык «PDF Мастер» на рабочем столе и в меню «Пуск».

Первый запуск занимает 5–15 минут (скачиваются библиотеки), последующие обновления — 2–4 минуты.

**Начиная с версии 1.1** архив распаковывать не нужно: в программе
**Справка → Установить обновление из архива…** → выберите скачанный zip. Программа закроется,
обновится и откроется снова.

Номер версии — в **Справка → О программе**.

## Если что-то сломалось

Ошибки записываются в журнал: **Справка → Журнал ошибок → «Скопировать последние ошибки»** —
и вставьте в чат вместе с описанием, что делали. Если не получилась сама установка —
пришлите текст из окна и файл `%LOCALAPPDATA%\PDFMaster-build\update.log`.

## Три раздела (кнопки слева)

- **Документ** — работа с PDF: страницы, редактирование, конвертация, а также инструменты «Для суда и почты» и «Материалы дела».
- **Дела** — карточки дел: сведения, сроки и заседания (с напоминаниями), документы, время и оплата, выписки.
- **Расчёты** — процессуальные сроки, госпошлина, проценты по ст. 395 ГК и неустойка.

У сложных функций стоит кнопка **?** — там подробно описано, что делает функция и какие требования учитывает.
Справочные данные (ключевая ставка ЦБ, ИПЦ, производственный календарь, госпошлина) актуальны на дату выпуска версии и обновляются вместе с программой.
Дела и заметки хранятся только на вашем компьютере: `%LOCALAPPDATA%\PDFMaster\cases.sqlite`.

## Основная работа

- **Открыть / Добавить** PDF, картинки, Word/Excel/PowerPoint, HTML, XPS, EPUB, TXT — все файлы собираются в один документ. Файлы можно просто перетащить в окно.
- **Порядок страниц** — перетаскивайте миниатюры мышью. Выделение нескольких страниц: Ctrl/Shift.
- Поворот, удаление, дублирование, пустые страницы, извлечение выбранных страниц в отдельный файл.
- **Вид → Тема оформления**: как в Windows, светлая или тёмная.
- Размер выбранной страницы (например, «A4 книжная (210×297 мм)») показан в строке состояния внизу.
- Отмена/повтор (Ctrl+Z / Ctrl+Y), **Сохранить** (Ctrl+S) — всё сохраняется одним PDF.
- **✎ Редактировать** (двойной щелчок по странице): текст, замена текста, картинки, подпись, выделение, фигуры, стрелки, карандаш, заметки, ссылки, закраска, скрытие данных, обрезка, поля форм, ластик.

## Инструменты (панель слева)

| Раздел | Функции |
|---|---|
| Организация | объединить, разделить (каждая страница / каждые N / диапазоны), упорядочить, повернуть, **размер страниц** (A0–A6, B4/B5, Letter, Legal, Tabloid, конверты или свой размер в мм; ориентация; вписать/растянуть/без масштаба; поля), пустые страницы нужного формата |
| Оптимизация | сжать (3 уровня), восстановить повреждённый PDF, OCR (русский + английский) |
| Конвертировать в PDF | JPG/PNG в PDF, Word/Excel/PowerPoint в PDF, HTML/URL в PDF, PDF в PDF/A |
| Конвертировать из PDF | в Word, Excel, PowerPoint, JPG/PNG, извлечь изображения, в текст, в Markdown |
| Редактирование | водяной знак (текст/картинка), номера страниц, обрезка полей, подпись, заполнение форм, метаданные |
| Безопасность | поставить/снять пароль (AES-256, права), скрыть данные (поиск по словам и шаблонам: email, телефоны, карты, паспорт), сравнение двух PDF |

## Что требует дополнительных программ (необязательно)

- **Word/Excel/PowerPoint → PDF**: Microsoft Office или бесплатный LibreOffice.
- **HTML/сайт → PDF**: Edge, Chrome или Яндекс.Браузер (Edge есть в Windows по умолчанию). Без них — упрощённая конвертация.
- **PDF/A**: Ghostscript (https://ghostscript.com/releases/gsdnld.html).
- **OCR** работает сразу (языки rus/eng в папке `tessdata`). Другие языки: положите нужный `*.traineddata` из https://github.com/tesseract-ocr/tessdata_fast в эту папку.
