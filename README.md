## Как установить (впервые) — 4 шага

> Понадобится Windows 10 или 11 и интернет. Первая установка занимает **10–20 минут**
> (программа сама скачивает всё нужное), потом обновления ставятся сами за пару минут.

**Шаг 1. Скачайте.** Нажмите синюю кнопку **«Скачать LegalHelper»** выше. Браузер скачает файл
`LegalHelper-main.zip` — обычно в папку **«Загрузки»**.

**Шаг 2. Распакуйте архив.** Откройте папку «Загрузки», щёлкните по `LegalHelper-main.zip`
**правой кнопкой мыши** → **«Извлечь все…»** → **«Извлечь»**. Откроется папка `LegalHelper-main`.
⚠️ Важно именно *извлечь*: если просто открыть архив двойным щелчком, установка не запустится.

**Шаг 3. Запустите установку.** В папке `LegalHelper-main` дважды щёлкните файл **`УСТАНОВИТЬ`**
(или `УСТАНОВИТЬ.bat`).
- Если появится синее окно **«Windows защитила ваш компьютер»** — нажмите **«Подробнее»** →
  **«Выполнить в любом случае»**. Это обычное предупреждение для программ, скачанных не из магазина.
- Если на компьютере нет Python (это «двигатель» программы), установка поставит его сама.
  Если попросит — разрешите, нажав «Да».
- Откроется чёрное окно с ходом установки. **Не закрывайте его** — просто подождите.

**Шаг 4. Готово.** Программа откроется сама, а на рабочем столе появится ярлык **LegalHelper**.
При первом запуске программа предложит **короткое обучение со стрелками** — очень советуем пройти.

### Если что-то не получилось
- **Окно сразу закрылось или пишет «запущен прямо из архива»** — вы не распаковали архив. Вернитесь к шагу 2.
- **Пишет «Python не установился»** — откройте [python.org/downloads](https://www.python.org/downloads/),
  нажмите «Download Python», в установщике **обязательно отметьте галочку «Add python.exe to PATH»**,
  нажмите «Install Now», затем снова запустите `УСТАНОВИТЬ`.
- **Антивирус ругается** — разрешите файл: программа собирается прямо на вашем компьютере из открытого кода.
- Не помогло — напишите разработчику: почта **axis.juris@bk.ru**, Telegram **@axis_juris**.
  Приложите текст из чёрного окна и файл `%LOCALAPPDATA%\PDFMaster-build\update.log`.

### Для тех, кто разбирается
Скрипт `update.bat` (его вызывает `УСТАНОВИТЬ.bat`) находит Python, собирает программу в
`%LOCALAPPDATA%\PDFMaster-build` и ставит её: поверх версии, установленной установщиком, или в
`%LOCALAPPDATA%\Programs\LegalHelper` с ярлыками на рабочем столе и в «Пуске».

## Обновление

**С версии 1.6 — само:** при запуске программа проверяет, нет ли на GitHub новой версии. Если есть — сверху
появляется плашка «Доступна новая версия» с кнопками **Что нового**, **Установить сейчас** и **Позже**.
Проверить вручную — **Справка → Проверить обновления…**; выключить автопроверку — там же.

**С версии 1.5 и раньше на 1.6 — один раз вручную:** скачайте **Code → Download ZIP** и в программе выберите
**Справка → Установить обновление из архива…**. Дела, шаблоны и настройки сохранятся, ярлыки «PDF Мастер»
заменятся на «LegalHelper».

Номер версии — в **Справка → О программе**.

### Как выпустить новую версию (для разработчика)

Ветка `main` — это всегда выпущенная версия: программа читает `version.json` из `main`
и скачивает архив `main`. Поэтому изменения готовятся в отдельной ветке и попадают в `main` только при выпуске:

1. Поднять `APP_VERSION` в `pdf_master.py` и `MyAppVersion` в `installer.iss`, дописать `CHANGELOG.md`.
2. В `version.json` указать ту же версию и список изменений (`notes`) — его увидит пользователь.
3. Влить ветку в `main`. Пользователи увидят уведомление при следующем запуске программы
   (GitHub может отдавать старый `version.json` ещё несколько минут).

## Если что-то сломалось

Ошибки записываются в журнал: **Справка → Журнал ошибок → «Скопировать последние ошибки»** —
и вставьте в чат вместе с описанием, что делали. Если не получилась сама установка —
пришлите текст из окна и файл `%LOCALAPPDATA%\PDFMaster-build\update.log`.

## Основная работа

- **Открыть / Добавить** PDF, картинки, Word/Excel/PowerPoint, HTML, XPS, EPUB, TXT — все файлы собираются в один документ. Файлы можно просто перетащить в окно.
- **Порядок страниц** — перетаскивайте миниатюры мышью. Выделение нескольких страниц: Ctrl/Shift.
- Поворот, удаление, дублирование, пустые страницы, извлечение выбранных страниц в отдельный файл.
- **Вид → Тема оформления**: как в Windows, светлая или тёмная.
- Размер выбранной страницы (например, «A4 книжная (210×297 мм)») показан в строке состояния внизу.
- Отмена/повтор (Ctrl+Z / Ctrl+Y), **Сохранить** (Ctrl+S) — всё сохраняется одним PDF.
- **✎ Редактировать** (двойной щелчок по странице): текст, замена текста, картинки, подпись, выделение, фигуры, стрелки, карандаш, заметки, ссылки, закраска, скрытие данных, обрезка, поля форм, ластик.

## Что требует дополнительных программ (необязательно)

- **Word/Excel/PowerPoint → PDF**: Microsoft Office или бесплатный LibreOffice.
- **HTML/сайт → PDF**: Edge, Chrome или Яндекс.Браузер (Edge есть в Windows по умолчанию). Без них — упрощённая конвертация.
- **PDF/A**: Ghostscript (https://ghostscript.com/releases/gsdnld.html).
- **OCR** работает сразу (языки rus/eng в папке `tessdata`). Другие языки: положите нужный `*.traineddata` из https://github.com/tesseract-ocr/tessdata_fast в эту папку.
