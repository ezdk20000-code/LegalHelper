# PDF Мастер 1.0 — настольный редактор PDF для Windows

## Установка

1. Распакуйте архив в любую папку (например, `C:\PDFMaster-src`). Путь лучше без кириллицы и пробелов.
2. Дважды щёлкните **`build_exe.bat`**. Скрипт сам:
   - найдёт Python (если его нет — попробует поставить через winget; иначе поставьте Python 3.10+ с python.org, отметив «Add python.exe to PATH»);
   - установит библиотеки и соберёт `dist\PDFMaster\PDFMaster.exe` (5–15 минут, нужен интернет);
   - если установлен **Inno Setup 6** (https://jrsoftware.org/isdl.php) — соберёт полноценный установщик `installer_output\PDFMaster_Setup.exe` (ярлыки, «Открыть с помощью» для PDF, удаление через «Приложения»);
   - если Inno Setup нет — создаст ярлык «PDF Мастер» на рабочем столе.
3. Готовую папку `dist\PDFMaster` или установщик можно переносить на другие компьютеры — Python там не нужен.

Для запуска без сборки (после первого запуска build_exe.bat) есть `run.bat`.

## Основная работа

- **Открыть / Добавить** PDF, картинки, Word/Excel/PowerPoint, HTML, XPS, EPUB, TXT — все файлы собираются в один документ. Файлы можно просто перетащить в окно.
- **Порядок страниц** — перетаскивайте миниатюры мышью. Выделение нескольких страниц: Ctrl/Shift.
- Поворот, удаление, дублирование, пустые страницы, извлечение выбранных страниц в отдельный файл.
- Отмена/повтор (Ctrl+Z / Ctrl+Y), **Сохранить** (Ctrl+S) — всё сохраняется одним PDF.
- **✎ Редактировать** (двойной щелчок по странице): текст, замена текста, картинки, подпись, выделение, фигуры, стрелки, карандаш, заметки, ссылки, закраска, скрытие данных, обрезка, поля форм, ластик.

## Инструменты (панель слева)

| Раздел | Функции |
|---|---|
| Организация | объединить, разделить (каждая страница / каждые N / диапазоны), упорядочить, повернуть |
| Оптимизация | сжать (3 уровня), восстановить повреждённый PDF, OCR (русский + английский) |
| Конвертировать в PDF | JPG/PNG в PDF, Word/Excel/PowerPoint в PDF, HTML/URL в PDF, PDF в PDF/A |
| Конвертировать из PDF | в Word, Excel, PowerPoint, JPG/PNG, извлечь изображения, в текст, в Markdown |
| Редактирование | водяной знак (текст/картинка), номера страниц, обрезка полей, подпись, заполнение форм, метаданные |
| Безопасность | поставить/снять пароль (AES-256, права), скрыть данные (поиск по словам и шаблонам: email, телефоны, карты, паспорт), сравнение двух PDF |

## Что требует дополнительных программ (необязательно)

- **Word/Excel/PowerPoint → PDF**: Microsoft Office или бесплатный LibreOffice.
- **HTML/сайт → PDF**: Edge, Chrome или Яндекс.Браузер (Edge есть в Windows по умолчанию). Без них — упрощённая конвертация.
- **PDF/A**: Ghostscript (https://ghostscript.com/releases/gsdnld.html).
- **OCR** работает сразу (языки rus/eng в папке `tessdata`). Другие языки: положите нужный `*.traineddata` из https://github.com/tesseract-ocr/tessdata_fast в эту папку.
