# Бланки

- `f107_blank.pdf` — пустой официальный бланк описи вложения ф. 107 Почты России (как формирует pochta.ru).
  Получен из бланка с pochta.ru удалением введённых данных; программа впечатывает данные в те же места
  (координаты — в `legal_core.py`, константы `F107_*`).
- `LiberationSans-Bold.ttf` — шрифт Liberation Sans Bold (SIL Open Font License 1.1), метрически совместим
  с Arial Bold. Используется, только если в Windows нет `arialbd.ttf`.
